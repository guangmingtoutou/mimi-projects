物理试卷分析系统 - 使用说明（绿色免安装版）
================================================

一、如何运行
1. 将整个文件夹解压到任意位置（路径建议不要包含空格和特殊字符，中文路径可以）。
2. 双击 start.bat。
3. 等待 2~3 秒，浏览器会自动打开系统页面：
   http://127.0.0.1:8787
4. 关闭黑色命令行窗口即停止服务。

二、系统要求
- Windows 10 / 11（64位），无需安装 Python，无需联网（大模型模式除外）。
- 导出 PDF / 图片 依赖系统自带的 Microsoft Edge 或 Chrome（Windows 10/11 均自带 Edge）。

三、功能速览
1. 个人试卷分析：导入试卷（图片/PDF/Word）→ 配置题目（题型/板块/分值/得分，得分<满分即错题）
   → 生成报告 → 导出 PDF 或图片。
2. 批量试卷分析：上传试卷与 xlsx 答题数据（含“正确答案”行）→ 填写考试名称（可留空）→
   选择老师 → 一键为该老师名下所有学生生成报告并打包 zip 下载（可选 PDF / 图片 / PDF+图片）。
   生成前系统会自动检查：非纯规则模式是否已配置 API Key、各题满分合计是否为 100 分、
   知识视频目录是否为空，发现问题会阻止生成并提示。
3. 知识视频目录：分别维护“目标班”“菁英班”两套目录，上传截图自动 OCR 识别视频标题，
   并自动匹配绑定高考大纲知识点（可多选、可手动修改，或点“🤖 自动匹配知识点”一键预填）。
   报告的“三、强化学习”以知识视频为核心：错题知识点精确对应到绑定视频（绑定优先），
   每个知识点只推荐 1 个主推视频，其余折叠为“＋N 个相关视频”，错题不会重复匹配。
4. 设置：分析模式（纯规则 / 大模型 API / 混合）、学校名称、多选题部分得分。
   如需大模型智能分析，在“设置”页填写 DeepSeek API Key。

四、数据说明
- 所有数据保存在本机 data 文件夹（答题上传、目录、历史报告），不会上传任何服务器。
- 历史报告可在“历史记录”页查看和重新下载。

五、常见问题
- 端口被占用：提示地址被占用时，请关闭其他占用 8787 端口的程序后重试。
- 导出失败：请确认系统已安装 Microsoft Edge 或 Chrome。
- 大模型模式无输出：设置页填写 DeepSeek API Key（需联网）。
- 批量生成被阻止：按提示检查分析模式 / 题目满分合计（应为 100 分）/ 学科配置中的知识视频目录。
